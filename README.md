【一、核心功能与手机互传教程】

电脑端运行本软件，记下屏幕上显示的 4 位安全 PIN 码。
手机连上同一 WiFi，扫二维码（务必用自带相机扫码，微信扫码需点右上角在浏览器打开）。
手机端输入电脑上的 PIN 码即可进入系统。
【手机互传】手机A进入系统后上传文件到电脑，手机B扫码进入系统后，即可在文件列表中看到手机A传的文件，点击下载即可。电脑全程作为无损中转站。
【在线预览】手机端点击文本、图片、PDF等文件，可直接在网页中打开预览，无需下载。
【聊天功能】手机端右下角点开聊天气泡，发送文字、图片、文件，另一台手机端会实时弹窗提示。

【二、多选与批量操作】

在手机端文件列表右上角，点击【多选】图标。
直接点击文件或文件夹所在行，即可打勾选中。
点击底部操作栏的【打包下载】一键下载压缩包，点击【删除】批量删除。
点击底部左侧【取消多选】退出多选模式。

【三、保姆级排错指南】
如果手机扫码后无法访问，请按以下步骤依次排查：
① 检查网络：确保手机和电脑连接的是同一个路由器（同一个 WiFi 名称）。
② 权限拦截：请关闭电脑端的“以管理员身份运行”重新打开软件，或者手动在 Windows 防火墙中允许 Python/本软件通过。
③ 代理冲突：如果电脑开启了 Clash、V2Ray 等代理软件，请暂时关闭它们，或在代理软件中设置“允许局域网连接”。
④ IP 选错：如果电脑有虚拟机（如 VMware），右上角可能显示的是虚拟 IP。请在主界面“本机局域网 IP”下拉框中切换成真实的 WiFi IP。
⑤ 浏览器拦截：如果是微信/QQ扫码白屏，请点击右上角“···”选择“在浏览器中打开”。
⑥ 局域网隔离：部分公司/学校网络开启了 AP 隔离，禁止设备互访。请用手机开热点给电脑连，或者换家庭路由器测试。

【四、在外网/外面怎么访问？】
由于没有公网 IP，必须使用内网穿透工具（如 FRP、花生壳）。将本机端口映射到公网域名，然后把域名填入主界面的“外网地址”框即可。

【五、关于配置文件】
lanshare_config.json 用于保存目录设置，删除它不影响使用。
